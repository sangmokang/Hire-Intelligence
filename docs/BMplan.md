## 1. Executive Summary

### 한 줄 요약

> Hire Intelligence는 채용 시장 데이터 인텔리전스(B2B) + AI 기반 후보자 정제(B2C) + 헤드헌팅 연결(마켓플레이스)의 3층 구조 BM이다.

### 8명의 에이전트 종합 점수

| 평가 항목 | PM | UX | Biz Analyst | Critic | Historian | Metis-AI | **합의** |
|-----------|:--:|:--:|:-----------:|:------:|:---------:|:--------:|:--------:|
| 시장 니즈 존재 | 8/10 | 8/10 | - | 7/10 | - | - | **7.5/10** |
| PMF 강도 (전체) | 7/10 | 7/10 | - | 5/10 | - | - | **6.5/10** |
| 수익 모델 실현성 | 6/10 | - | 4/10 | 3/10 | - | 5/10 | **5.5/10** |
| 경쟁 방어력 | 6/10 | - | - | 2/10 | - | - | **4/10** |
| 법적 안정성 | - | - | - | 2/10 | - | - | **2/10** |
| 실행 가능성 | 5/10 | - | 4/10 | 4/10 | - | - | **4.5/10** |
| 과금 당위성 | - | - | 7/10 | 5/10 | 8/10 | 7/10 | **7/10** |

### 핵심 합의 사항

1. **시장 니즈는 실재한다** — 채용 인텔리전스 수요는 8명 모두 인정
2. **B2B First가 정답이다** — 구직자 유료화보다 서치펌/HR 타겟이 우선
3. **AI 모의 인터뷰는 시기상조** — PM과 Critic 합의, UX는 반대 의견
4. **데이터 소싱 합법화가 생존 전제조건** — 스크래핑 의존은 치명적 리스크
5. **범위 축소 + 속도 우선** — 6개 뷰 전부가 아닌 2~3개로 빠른 MVP
6. **과금의 당위성은 역사적으로 입증되었으나, 한국 시장 특수성 반영 필수** — Historian과 Critic 합의
7. **Conservative 시나리오(Y1 ARR 1.5억)를 기본 계획으로** — Revenue Architect와 Critic 합의
8. **구독자 가치 > 비용의 정량적 증명이 생존의 전제조건** — Value Architect 제안, 전원 합의

## 2. BM 개요

### 서비스 컨셉

```
┌─────────────────────────────────────────────────────────┐
│                   Hire Intelligence                      │
│                                                          │
│  Layer 1: 채용 시장 인텔리전스 (데이터 대시보드)            │
│  ├─ S/D Matrix (수요/공급 비율)                           │
│  ├─ Company Analysis (기업별 인재 밀도)                    │
│  ├─ Segment Trends (직군별 추이)                          │
│  └─ Keyword Intelligence (키워드 트렌드)                   │
│                                                          │
│  Layer 2: AI 후보자 정제                                   │
│  ├─ Career Path Intelligence (커리어 패스 분석)            │
│  ├─ AI Mock Interview (모의 인터뷰 → 후보자 에센스)        │
│  └─ Resume Enhancement (이력서 정제)                       │
│                                                          │
│  Layer 3: 매칭 & 연결                                      │
│  ├─ Refined Resume → 헤드헌터 연결                         │
│  └─ Candidate → Executive 직접 연결                        │
└─────────────────────────────────────────────────────────┘
```

## 3. SW 과금의 역사적 당위성

> **발화자: SW 과금 역사가 (Historian)**

### SW 과금 모델의 40년 진화 타임라인

| 시대 | 과금 모델 | 대표 사례 | 핵심 특징 |
|------|----------|----------|----------|
| **1980~90년대** | 패키지 라이선스 | MS Office $495~$999, Oracle per-processor 라이선스 | 일회성 구매, 업그레이드 별도 과금 |
| **2000년대** | SaaS 전환 | Salesforce 월 $65, "No Software" 선언 (2004 IPO $96M → 2024 $34.9B) | 구독 모델 등장, 초기 시장 저항 극복 |
| **2010년대** | Freemium | Dropbox 전환율 4% but ARR $1.1B, Slack 30% 전환율, Spotify 37.5% | 무료 사용자 기반 위 유료 전환 |
| **2020년대** | Usage-based | Snowflake NRR 131%, Twilio API 건당 과금, Stripe 2.9%+$0.30 | 사용량 비례, 투명한 원가 구조 |
| **2024~2026** | AI-native | OpenAI 토큰 과금, Cursor ARR $100M in 2년, GitHub Copilot 하이브리드 | 가치 기반 + 사용량 혼합 |

### "왜 소프트웨어에 돈을 내야 하는가?" 3축 논리

| 축 | 논리 | Hire Intelligence 적용 |
|----|------|----------------------|
| **시간 절약** | 채용 담당자 소싱 6~8시간 → 30분~1시간 (건당 $200~$400 가치) | 데이터 수집/분석 자동화로 서치펌 시간 절감 |
| **의사결정 품질** | Bad hire 비용 = 연봉의 50~200% (SHRM 기준) | 데이터 기반 채용 의사결정으로 미스매치 감소 |
| **접근성 민주화** | 헤드헌팅 수수료 연봉 20~33% → SaaS로 월 수십만원 | 대형 서치펌만 보유하던 시장 인텔리전스를 소규모 서치펌/인하우스 HR에 개방 |

### 한국 시장 특수성

| 요인 | 현황 | 시사점 |
|------|------|--------|
| **"SW는 공짜" 인식** | 네이버/카카오 무료 전략이 형성한 소비자 기대 | B2C 과금 장벽 높음, B2B부터 공략 필수 |
| **불법복제율** | OECD 평균 20% vs 한국 32% (2023) | SW 유료 구매 문화 상대적 취약 |
| **SI 문화** | 프로젝트 단위 발주에 익숙, 구독형 SaaS 미숙 | 연간 계약 + ROI 증명이 판매 핵심 |
| **BUT 성장세** | 한국 B2B SaaS 시장 2023년 1.8조 → 2026년 3.2조 (CAGR 21%) | 시장 교육 비용 감소 추세, 진입 타이밍 적절 |

### 성공 사례 시사점

| 서비스 | 과금 전략 | 핵심 지표 | Hire Intelligence 시사점 |
|--------|----------|----------|------------------------|
| **LinkedIn** | 10억 사용자 중 4~5% 전환, Recruiter $10K+/year/seat | 유료 전환율 낮아도 절대 매출 거대 | B2C 무료 기반 위 B2B 고가 과금 구조 벤치마크 |
| **Notion** | 개인 무료 → 팀 유료, bottom-up adoption, AI 번들 +$8~10 | 팀 전환이 핵심 성장 동력 | 헤드헌터 개인 → 서치펌 팀 전환 유도 |
| **Figma** | 뷰어 무료 → 에디터 과금, ARR $600M | 무료 사용자가 유료 사용자를 끌어들임 | 구직자(뷰어) 무료 → 서치펌(에디터) 과금 |
| **블라인드** | B2C 무료 데이터 축적 → B2B 연 $50K~$200K/기업 | 사용자 생성 데이터가 B2B 가치의 원천 | 구직자 프로필/AI 면접 데이터 → B2B 인텔리전스 |

### Hire Intelligence 과금 로드맵 시사점

```
0단계 (무료/클로즈드 베타)
  → 데이터 품질 검증 + 초기 사용자 피드백 수집
  │
1단계 (Freemium + 팀 과금)
  → B2C 무료 유입, B2B 서치펌/HR 팀 단위 유료 구독

2단계 (하이브리드 구독 + 사용량)
  → 기본 구독료 + AI 면접/리포트 건별 추가 과금
  │
3단계 (성과 기반)
  → 매칭 성공 시 수수료, 채용 확정 시 성과보수
```

## 5. ARR/MRR 안정화 전략

> **발화자: ARR/MRR 전략가 (Revenue Architect)**

### 안정적 반복매출의 5대 원칙

| 원칙 | 설명 | 목표 |
|------|------|------|
| **NRR > 100%** | 기존 고객 확장 매출 > 이탈 매출 | 120%+ (SaaS 우수 기준) |
| **Expansion Revenue 설계** | Upsell(시트 추가), Cross-sell(리포트), Usage(AI 면접) | 고객당 ARPU 분기별 10% 증가 |
| **Churn 방지의 구조적 설계** | Switching cost, workflow embedding, 데이터 축적 lock-in | 월 churn 3% 이하 |
| **연간 선불 계약 비율** | 캐시플로우 안정화 + 이탈 방지 | 40%+ 목표 |
| **Multi-year contract 인센티브** | 장기 계약으로 매출 예측 가능성 확보 | 2년 계약 시 20% 할인 |

### Hire Intelligence 맞춤 ARR 구조

| 수익원 | 유형 | 비중 목표 (Y1) | 비중 목표 (Y3) |
|--------|------|:-------------:|:-------------:|
| B2B SaaS 구독 (서치펌/HR) | 반복 | 70% | 40% |
| B2C 프리미엄 구독 | 반복 | 10% | 20% |
| AI 면접/리포트 건별 과금 | 사용량 | 5% | 15% |
| 마켓플레이스 매칭 수수료 | 성과 | 0% | 20% |
| 데이터 리포트 단건 판매 | 일회성 | 15% | 5% |

### 현실적 매출 시나리오

| 시나리오 | Y1 ARR | Y2 ARR | Y3 ARR | 핵심 가정 |
|----------|--------|--------|--------|-----------|
| **Conservative** | **1.5억** | **8억** | **25억** | 서치펌 20곳 PRO, churn 8%/월 |
| Base | 3억 | 15억 | 50억 | 서치펌 40곳 + HR 10곳, churn 5%/월 |
| Optimistic | 5억 | 30억 | 100억 | 서치펌 60곳 + HR 30곳 + B2C 5,000명, churn 3%/월 |

### 비평가 반론 (Critic 반박)

| 지적 사항 | 근거 |
|----------|------|
| Year 1 ARR 5~10억은 비현실적 | 서치펌 30~50곳 x 월 29만원 = 연 1~1.7억이 현실 |
| 한국 서치펌 IT 도구 예산 | 대부분 월 10만원 미만 |
| 월 churn 5~8% → 연간 유지율 | 36~54%에 불과 |

> **합의**: Conservative 시나리오를 기본 계획으로, 나머지는 stretch goal로 설정. 초기 매출 기대치를 현실적으로 조정해야 투자자 신뢰 확보 가능.

### 매출 안정성 전술

| 전술 | 메커니즘 | 기대 효과 |
|------|----------|----------|
| **Annual prepay 할인** | 연 선불 시 15~20% 할인 | 캐시플로우 안정화, 이탈 감소 |
| **데이터 축적 lock-in** | 52주 시계열 데이터가 쌓일수록 떠나기 어려움 | 자연적 switching cost 형성 |
| **ATS 통합** | 기존 워크플로우에 임베딩 | 해지 시 업무 프로세스 변경 필요 |
| **주간 인텔리전스 리포트** | 매주 자동 발송으로 습관 형성 | 사용 빈도 유지, 가치 체감 지속 |

## 6. 구독자 가치 설계

> **발화자: 가치 설계자 (Value Architect)**

### 핵심 질문

> "구독자가 돈을 내는 것보다 **훨씬 더 큰 가치**를 얻고 있다고 느끼게 하려면?"

### 세그먼트별 10x 가치 설계

| 세그먼트 | 구독료 | 1건 성과의 경제적 가치 | ROI | 가치 체감 포인트 |
|----------|--------|----------------------|-----|-----------------|
| **헤드헌터** | 월 29만원 | 성공보수 1건 = 1,000~2,000만원 | 3,400~6,900% | "이 데이터로 클라이언트에 정량적 제안서 작성" |
| **구직자** | 월 9,900원 | 연봉 협상 +100만원 | 연 1,000% | "내 시장가치가 상위 15%라는 근거 확보" |
| **인하우스 HR** | 월 29만원 | 잘못된 채용 1건 방지 = 연봉의 50~200% | 8,600~34,400% | "채용 시장 수급 데이터로 경영진 설득" |
| **CHRO** | 연 계약 | 채용 전략 최적화 = 수억원 규모 | 측정 불가 | "인재 밀도를 숫자로 경영회의에서 보고" |

### 비평가 반론: "10x 가치 주장의 허구"

| 지적 | 설명 |
|------|------|
| **상관관계 ≠ 인과관계** | 도구 사용 → 추가 성사를 증명 불가 |
| **관계 게임** | 헤드헌팅은 "정보 게임"이 아니라 "관계 게임" |
| **Incremental value 불분명** | LinkedIn Recruiter 대비 추가 가치 측정 어려움 |

> **가치 설계자 재반론**: 정보 → 관계 전환의 촉매제 역할. 데이터가 관계를 대체하는 게 아니라, **관계 구축의 시작점을 앞당긴다**. 헤드헌터가 클라이언트에게 정량적 시장 데이터를 제시하면 신뢰도가 상승하고, 이것이 관계 강화로 이어진다.

### 심리적 가치 5-Layer Model

| Layer | 가치 유형 | 설명 | Retention 영향 |
|:-----:|----------|------|:-------------:|
| 1 | **기능적 가치** | 데이터, 분석 | 기본 (없으면 해지) |
| 2 | **시간 가치** | 수작업 대비 절약 | 정량화 가능 (ROI 계산 근거) |
| 3 | **의사결정 가치** | 더 나은 결정 | 핵심 차별점 |
| 4 | **사회적 가치** | 전문성 과시, "데이터 기반 의사결정" | 조직 내 위상 강화 |
| 5 | **감정적 가치** | 불안 해소, 자신감 | 가장 강력한 retention 요인 |

### ROI 체감 설계

| 터치포인트 | 메커니즘 | 목적 |
|-----------|---------|------|
| **대시보드 위젯** | "이번 달 절약한 시간: 42시간, 환산 가치: 420만원" | 실시간 ROI 가시화 |

| "Free API 일 100회가 적절한 paywall 임계점이다" | 세션당 평균 API 호출 수 측정 |

> **Biz Analyst 결론**: 재무 분석은 작성 가능하나, 위 Open Questions가 해소되지 않은 상태에서는 **가정 위에 가정을 쌓는 구조**가 된다. 플랜 가격표 확정, AI 인터뷰 원가 구조, 마켓플레이스 수수료 모델이 해결되어야 투자자 수준의 재무 모델 산출 가능.

### 쟁점 5: SW 과금의 당위성 — 한국 시장에서 가능한가?

| 에이전트 | 입장 |
|----------|------|
| **Historian** | 40년 SW 과금 역사가 증명한다. B2B에서 "공짜는 신뢰 못함" — 무료 도구는 오히려 의심을 산다. Salesforce도 초기 시장 저항을 극복했고, 한국 B2B SaaS 시장 CAGR 21%가 전환점을 시사한다. |
| **Critic** | 한국 채용 시장에서 데이터는 무료가 기본이다. 14개 세그먼트/50개 기업 커버리지는 월 29만원을 정당화하기엔 부족하다. 네이버/카카오가 만든 "무료 문화"는 B2B에서도 영향력이 크다. |
| **Metis-AI** | AI 기능 추가 시 프리미엄 정당화 가능하나, API 원가를 확인해야 한다. Free tier에서 AI 비용이 적자를 만드는 구조적 문제를 먼저 해결해야 과금 모델이 성립한다. |
| **Value Architect** | 10x 가치 설계로 심리적 장벽 극복 가능하다. 헤드헌터 월 29만원 vs 성공보수 1,000만원 = ROI 3,400%. ROI 체감 위젯이 핵심 설득 도구가 된다. |

**합의 도출**:
> B2B에서는 과금이 가능하다 — "공짜는 신뢰 못함"이라는 B2B 심리와 ROI 정량화가 핵심. B2C는 무료 우선 + 극소수 프리미엄 전략이 현실적. 다만, 데이터 커버리지 확대 없이 현재 수준으로 프리미엄 과금은 어렵다.

### 쟁점 6: 현실적 ARR 목표 — 얼마가 적정한가?

| 에이전트 | 입장 |
|----------|------|
| **Revenue Architect** | Base 시나리오 Y1 ARR 3억. 서치펌 40곳 + HR 10곳 확보를 가정. 수익원 다각화(구독 70% + 리포트 15% + B2C 10% + AI 건별 5%)로 안정적 구조 설계 가능. |
| **Critic** | 서치펌 144곳을 확보해야 5억인데, KESA 정회원이 120곳이다. 이 중 절반 이상을 Y1에 확보한다는 건 비현실적. Y1 현실적 상한 = 5천만~1.5억. 한국 서치펌 IT 도구 예산이 대부분 월 10만원 미만이라는 점도 고려해야 한다. |
| **Biz Analyst** | 데이터 리포트 단건 판매로 보조 매출을 확보하면 구독 매출 의존도를 낮출 수 있다. 구독 외 수익원 다각화가 초기 생존에 필수적이다. |

**합의 도출**:
> Conservative(1.5억)를 기본 계획으로, Base(3억)를 stretch goal로 설정. 데이터 리포트 단건 판매를 초기 캐시플로우 보조 수단으로 병행하되, 핵심은 B2B SaaS 구독 매출 확보.

### 쟁점 7: 경쟁 대응 — 원티드/LinkedIn이 같은 기능 출시하면?

| 에이전트 | 입장 |
